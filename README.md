# 小芽岛 · SproutIsle 🌱

一款面向 **3-6 岁学龄前小朋友** 的原生 **iOS / iPadOS (SwiftUI)** 趣味启蒙学习 App。  
离线优先、语音伴读、童趣交互，并支持在家长端可选接入任意 **OpenAI 兼容大模型**（如本地 `llm-lab`、Ollama、DeepSeek、OpenAI）实时创作专属绘本与解答「十万个为什么」。

---

## 五大探索小岛

| 小岛 | 核心玩法 |
|---|---|
| 🌱 **汉字谷**（趣味识字与拼音） | 32 个学龄前高频汉字卡片（米字格、笔顺提示、记忆儿歌、词语例句）、**手指彩色描红画板**、**四声调过山车**、**拼读小火车**与语音组词闯关 |
| 🔢 **数字屋**（趣味数学） | 分级难度（1-5 / 1-10 / 1-20）：**数数野餐**（逐个点击报数）、**看图加减口算**、**图形规律小火车**与生活形状小百科 |
| 🐳 **英语湾**（英语启蒙） | 完整 **A-Z 自然拼读卡片**、4 大主题 32 个词汇（动物/水果/颜色/交通自然）、**听音寻宝**与**开口跟读秀**（`en-US` 语音朗读 + `SFSpeechRecognizer` 跟读支持） |
| 🌳 **故事树**（AI 绘本与十万个为什么） | 4 本内置多页**互动分支绘本**（带语音伴读和剧情选择）、**魔法绘本机**（离线创作 + 可选 AI 实时生成）、16 篇精选**十万个为什么**及自由提问箱 |
| ⭐ **星星塔**（好习惯与贴纸墙） | 8 项每日好习惯打卡（支持自定义习惯）、**小芽宝成长树** 5 阶段进化、24 枚可兑换贴纸与**自由拖拽创意贴纸画板** |

### 🛡️ 家长小屋（安全门保护）
- **家长安全门**：随机成人算术题拦截，防止小朋友误操作设置
- **学习成长报告**：累计星星、识字数、数学正确率、英语词汇、连续天数与近 7 天趋势图（Swift Charts）
- **护眼定时休息**：支持 10/15/20/30 分钟护眼休息提醒与 20 秒远眺倒计时
- **OpenAI 兼容 AI 配置**：支持一键切换 `本机 llm-lab`、`Ollama`、`DeepSeek`、`OpenAI` 等预设，API Key 安全存储在系统 Keychain，支持一键测试连接

## 快速开始

### 环境要求
- macOS + Xcode 16+（支持 Swift 6 / iOS 17.0+ / iPadOS 17.0+）

### 运行方式
1. 使用 Xcode 打开 [`SproutIsle.xcodeproj`](SproutIsle.xcodeproj)
2. 选择任意 iPhone 或 iPad 模拟器（或真机）
3. 点击 **Run (`⌘R`)** 即可运行

### 命令行构建与单元测试
```bash
xcodebuild test \
  -project SproutIsle.xcodeproj \
  -scheme SproutIsle \
  -destination 'platform=iOS Simulator,name=iPhone Duo'
```

## 项目结构

```text
SproutIsle/
├── App/         # 应用入口与路由（SproutIsleApp, RootView）
├── Models/      # 领域模型（汉字、数学、英语、绘本、习惯与成长档案）
├── Data/        # 离线内容库与出题引擎（识字/拼音、数学生成、A-Z英语、互动绘本、贴纸）
├── Services/    # 本地存储、语音合成/跟读、木琴音效引擎、OpenAI 兼容客户端、护眼计时
├── Theme/       # 小芽岛视觉主题、3D 玩具按压组件、动态小芽宝吉祥物
├── Features/    # 首页地图、五大探索小岛与家长小屋
└── Resources/   # Assets（含 1024x1024 AppIcon）
```
